# Auri's Dalamud plugins

Plugin repository for Dalamud (FINAL FANTASY XIV, XIVLauncher).

## Install

1. In game, open the Dalamud settings: `/xlsettings`.
2. In the **Experimental** tab, under **Custom Plugin Repositories**, paste the address below, tick the box, click **+**, then **Save and Close**.

   ```
   https://raw.githubusercontent.com/AuriLumi/dalamud-plugins/main/repo.json
   ```

3. Open the plugin installer (`/xlplugins`), search for **Prisme** or **Cabine** and install it.

## Plugins

- <img src="plugins/Prisme/icon.png" alt="" width="32" align="top"> **Prisme**: organizes your Penumbra mods into views linked to collections, without copying the mods. Requires Penumbra.
- <img src="plugins/Cabine/icon.png" alt="" width="32" align="top"> **Cabine**: a fitting room that lets you try Penumbra mods on a 3D copy of your character, without changing your character or what others see. Requires Penumbra and an empty Penumbra collection named `_cabine`.

## Report a problem

- Something doesn't work: [open an issue](https://github.com/AuriLumi/dalamud-plugins/issues/new/choose) and pick the plugin. In Prisme, **Settings > Help > Report a problem** copies a report with the versions and the end of the log, and opens the form for you.
- A question or an idea: ask it in the [Discussions](https://github.com/AuriLumi/dalamud-plugins/discussions).

French or English, both are fine.
